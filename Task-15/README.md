# Simple Profit Analysis – Excel

## Project Overview

This project analyzes the **Sample Superstore dataset** using Microsoft Excel to compare total profit across different product categories.

The analysis helps identify the **most profitable category** and provides a simple visual comparison using a chart.

## Objective

- Calculate total profit for each product category.
- Identify the most profitable category.
- Calculate the highest profit.
- Calculate the average profit.
- Create a chart to compare category-wise profit.

## Tools Used

- Microsoft Excel
- Sample Superstore Dataset

## Analysis Performed

The following categories were analyzed:

- Furniture
- Office Supplies
- Technology

### Key Results

| Category | Total Profit |
|---|---:|
| Furniture | 18,451.27 |
| Office Supplies | 122,490.80 |
| Technology | 145,454.95 |

**Most Profitable Category:** Technology

**Highest Profit:** 145,454.95

**Average Profit:** 28.66

## Visualization

A column chart titled **"Profit by Category"** was created to visually compare the total profit generated by each product category.

## Key Findings

1. Technology generated the highest total profit.
2. Office Supplies generated the second-highest profit.
3. Furniture generated the lowest total profit.
4. Technology is the most profitable category in the dataset.

## Deliverable

- Excel workbook containing the profit analysis.
- Category-wise profit summary.
- Profit comparison chart.
- Key findings.
