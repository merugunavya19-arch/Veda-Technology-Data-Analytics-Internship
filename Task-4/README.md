## Superstore Excel Data Analysis
## 📌 Project Overview

This project was completed as part of my **internship Task 5: Excel Data Analysis.** The project analyzes Superstore sales data using **Microsoft Excel**, formulas, KPIs, and PivotTables to identify sales, profit, category, regional, monthly, and segment-level insights.

## 🎯 Objective

The main objective is to analyze business data and answer important questions related to:

Sales performance
Profit performance
Product categories
Regional sales
Monthly sales trends
Customer segments
## 🛠️ Tools Used
Microsoft Excel
Excel Formulas
PivotTables
Data Analysis
## 📊 Workbook Structure

The workbook contains the following sections:

**1. Raw Data**

Contains the original Superstore dataset. The raw data is kept separately without unnecessary modifications.

**2. Working**

Contains calculations and analysis using Excel formulas.

Formulas used include:

SUM
SUMIFS
COUNTIFS
AVERAGEIFS

The Working sheet includes analysis for:

Sales
Profit
Quantity
Discount
Region
Category
Month
**3. Summary**

Contains key performance indicators (KPIs):

Total Sales
Total Profit
Total Quantity
Average Sales
**4. PivotTables**

The workbook includes separate PivotTables for:

**Sales by Category**
**Sales by Region**
**Sales Trend by Month**
**Profit by Category**
**Sales by Segment**
## 📈 Key Analysis Areas

The analysis focuses on understanding:

Which category generates the most sales
Which region generates the most sales
How sales change over time
How profit varies across categories
How sales differ between customer segments
