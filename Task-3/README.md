# Data Visualization and Storytelling

This project was completed as part of my internship at **Veda Technology**.

## Objective

To transform structured Superstore sales data into meaningful visualizations and communicate business trends, patterns, and insights through a clear visual story.

## Tools Used

- Power BI
- Microsoft Excel
- DAX

## Analysis Covered

- Overall Sales and Profit Performance
- Monthly Sales Trends
- Category-wise Sales Analysis
- Regional Performance
- Profitability Analysis
- Key Business Insights

## Dashboard Features

- KPI Cards
- Sales by Category
- Profit by Category
- Monthly Sales Trend
- Sales by Region
- Profit by Region
- Interactive Filters

## Key Learning

This project helped me improve my skills in **Data Visualization, Data Analysis, Power BI, DAX, and Business Storytelling** by converting raw data into clear and meaningful insights.
